# SRT 字幕时间校正工具

供纪录片剪辑师使用的网页工具：粘贴或上传 SRT 字幕，录入若干“原片时间 → 成片时间”锚点，工具对每条字幕的起止时间做**分段线性映射**，输出校正后的 SRT；还可再上传一份成片时间轴上的**双语副轨 SRT**，自动做两轨字幕的一对一配对并导出 CSV。

## 功能

- 粘贴 SRT 文本或上传 `.srt` 文件
- 至少录入两个锚点；**原片时间、成片时间两组均须严格递增**，否则明确报错
- 相邻锚点之间线性插值；锚点范围之外沿用最近锚点的固定偏移；结果按毫秒取整
- 保留原序号与多行正文
- 页面展示每条字幕“原时间 / 新时间”对照表
- 若映射后出现**起止倒置**或**字幕顺序倒置**，阻止导出并逐条指出问题
- 一键下载校正后的 SRT
- **双语字幕对齐**：主轨沿用校正后的 SRT，再粘贴/上传一份成片时间轴上的副轨 SRT
  - 只允许时间区间**交叠严格大于 0** 的一对一配对（仅端点相接不算）
  - 用保持两轨顺序的动态规划，使**配对交叠毫秒数总和最大**；平分时取**起点差总和较小**的方案；再平分则取**配对序号靠前**的方案
  - 允许跳过任一侧无对应的字幕，页面分别展示配对与两侧未配对条目
  - 一键下载含**双方序号、起止时间、正文**的 CSV（未配对条目另一侧留空）
  - 副轨 SRT 解析失败时明确报错，但不影响主轨校正 SRT 的下载导出

## 使用说明

1. 在文本框粘贴 SRT 内容，或点击“选择文件”上传 `.srt`。
2. 添加至少两个锚点，格式为 `HH:MM:SS,mmm`（例如 `00:01:23,456`）：
   - **原片时间**：字幕当前（错误）的时间轴上的参考点
   - **成片时间**：该参考点在成片时间轴上的正确位置
3. 点击“开始校正”，页面显示原时间与新时间对照表。
4. 无错误时点击“下载校正后的 SRT”导出结果。
5. （可选）双语对齐：在“4. 双语字幕对齐”中粘贴或上传**同一成片时间轴**上的副轨 SRT（如英文字幕），点击“开始对齐”：
   - 页面按时间轴顺序展示配对行，以及主轨、副轨各自未配对的条目；
   - 副轨内容无效时会给出解析错误，主轨 SRT 仍可正常下载；
   - 点击“下载对齐结果 CSV”导出含双方序号、时间、正文的对照表。

## 映射规则

设锚点为 `(s₁→d₁), (s₂→d₂), …, (sₙ→dₙ)`（`s`、`d` 各自严格递增），对任意时间 `t`：

- `t ≤ s₁`：`t' = t + (d₁ − s₁)`（沿用首锚点固定偏移）
- `t ≥ sₙ`：`t' = t + (dₙ − sₙ)`（沿用末锚点固定偏移）
- `sᵢ ≤ t ≤ sᵢ₊₁`：线性插值 `t' = dᵢ + (t − sᵢ) · (dᵢ₊₁ − dᵢ) / (sᵢ₊₁ − sᵢ)`

每条字幕的开始、结束时间分别独立映射，结果四舍五入到毫秒。

## API

### `POST /api/convert`

```json
{
  "srt": "1\n00:00:01,000 --> 00:00:03,000\n字幕\n",
  "anchors": [
    { "src": "00:00:01,000", "dst": "00:00:02,000" },
    { "src": "00:00:12,000", "dst": "00:00:15,000" }
  ]
}
```

返回每条字幕的对照信息；无错误时附带 `srt` 字段（校正后的完整文本），存在倒置问题时 `errors` 非空且不返回 `srt`。

### `POST /api/align`

```json
{
  "srt": "主轨原始 SRT……",
  "anchors": [{ "src": "00:00:01,000", "dst": "00:00:02,000" }],
  "secondarySrt": "成片时间轴上的副轨 SRT……"
}
```

服务端先复用 `/api/convert` 的同一套逻辑校正主轨，再解析副轨并对齐。成功（200）时返回：

- `srt`：校正后的主轨 SRT（与 `/api/convert` 完全一致，供下载）
- `pairs`：配对数组，每项含双方 `index/start/end/text` 及交叠毫秒数 `overlapMs`
- `unmatchedMain` / `unmatchedSecondary`：两侧未配对条目
- `csv`：含双方序号、时间、正文的完整 CSV（UTF-8 BOM，未配对条目另一侧留空）

失败（400）情形：

- 主轨锚点/SRT 问题：返回 `anchorErrors` 或 `parseErrors`（与 `/api/convert` 相同）
- 副轨为空或解析失败：返回 `secondaryParseErrors`，**同时仍带 `srt` 字段**，不影响主轨导出
