# SRT 字幕时间校正工具

供纪录片剪辑师使用的网页工具：粘贴或上传 SRT 字幕，录入若干“原片时间 → 成片时间”锚点，工具对每条字幕的起止时间做**分段线性映射**，输出校正后的 SRT；并可将校正后的主轨与成片时间轴上的副轨 SRT 做**双语字幕对齐**，导出对照 CSV。

## 功能

- 粘贴 SRT 文本或上传 `.srt` 文件
- 至少录入两个锚点；**原片时间、成片时间两组均须严格递增**，否则明确报错
- 相邻锚点之间线性插值；锚点范围之外沿用最近锚点的固定偏移；结果按毫秒取整
- 保留原序号与多行正文
- 页面展示每条字幕“原时间 / 新时间”对照表
- 若映射后出现**起止倒置**或**字幕顺序倒置**，阻止导出并逐条指出问题
- 一键下载校正后的 SRT
- 双语字幕对齐：以校正后的主轨对副轨 SRT 做**保持顺序的一对一配对**（仅时间区间交叠 > 0 才可配对，允许跳过无对应字幕）
- 页面展示配对结果及两侧未配对条目，并可下载含双方序号、时间、正文的 CSV
- 副轨 SRT 无效时给出解析错误，不影响主轨 SRT 的导出

## 使用说明

1. 在文本框粘贴 SRT 内容，或点击“选择文件”上传 `.srt`。
2. 添加至少两个锚点，格式为 `HH:MM:SS,mmm`（例如 `00:01:23,456`）：
   - **原片时间**：字幕当前（错误）的时间轴上的参考点
   - **成片时间**：该参考点在成片时间轴上的正确位置
3. 点击“开始校正”，页面显示原时间与新时间对照表。
4. 无错误时点击“下载校正后的 SRT”导出结果。
5. 校正成功后，在第 4 步粘贴或上传**成片时间轴上的副轨 SRT**（另一语言），点击“开始对齐”：
   - 页面列出配对结果（含每对交叠毫秒数）与主轨、副轨两侧的未配对条目；
   - 点击“下载对齐 CSV”导出对照表；
   - 副轨解析失败时仅提示错误，主轨 SRT 的导出不受影响。

## 映射规则

设锚点为 `(s₁→d₁), (s₂→d₂), …, (sₙ→dₙ)`（`s`、`d` 各自严格递增），对任意时间 `t`：

- `t ≤ s₁`：`t' = t + (d₁ − s₁)`（沿用首锚点固定偏移）
- `t ≥ sₙ`：`t' = t + (dₙ − sₙ)`（沿用末锚点固定偏移）
- `sᵢ ≤ t ≤ sᵢ₊₁`：线性插值 `t' = dᵢ + (t − sᵢ) · (dᵢ₊₁ − dᵢ) / (sᵢ₊₁ − sᵢ)`

每条字幕的开始、结束时间分别独立映射，结果四舍五入到毫秒。

## 对齐规则

主轨为 `/api/convert` 成功返回的校正后 SRT，副轨为成片时间轴上的另一语言 SRT，两轨均按文件顺序参与配对：

- 仅当两条字幕的**时间区间交叠 > 0** 时才允许配对；配对为**一对一**且不得交叉（保持两轨顺序）；
- 用动态规划求使**配对交叠毫秒数总和最大**的方案；
- 平分时取**配对起点差 |主轨开始 − 副轨开始| 总和较小**的方案；
- 仍平分时**按序号靠前**确定结果：优先配对当前条目，其次跳过副轨条目，最后跳过主轨条目；
- 允许跳过无对应字幕的条目，未配对条目在页面与 CSV 中单独列出。

CSV 列为：`状态, 主轨序号, 主轨开始, 主轨结束, 主轨正文, 副轨序号, 副轨开始, 副轨结束, 副轨正文, 交叠毫秒`。先列出全部配对行，再依次列出主轨、副轨未配对行；文件带 BOM，可直接用 Excel 打开。

## 项目结构

```
├── server.js          # Express 服务（静态页面 + /api/convert + /api/align）

│   ├── time.js        # SRT 时间解析与格式化

├── public/            # 原生 JavaScript 前端
├── test/              # 核心逻辑测试
├── Dockerfile
└── compose.yaml
```

## API

`POST /api/convert`

```json
{
  "srt": "1\n00:00:01,000 --> 00:00:03,000\n字幕\n",
  "anchors": [
    { "src": "00:00:01,000", "dst": "00:00:02,000" },
    { "src": "00:00:12,000", "dst": "00:00:15,000" }
  ]
}
```

返回每条字幕的对照信息；无错误时附带 `srt` 字段（校正后的完整文本），存在倒置问题时 `errors` 非空且不返回 `srt`。

`POST /api/align`

```json
{
  "primary": "1\n00:00:02,000 --> 00:00:04,000\n你好\n",
  "secondary": "1\n00:00:02,500 --> 00:00:03,500\nHello\n"
}
```

- `primary`：主轨 SRT 文本（通常取 `/api/convert` 成功返回的 `srt` 字段）
- `secondary`：副轨 SRT 文本（成片时间轴）

成功时返回 `pairs`（含双方序号、时间、正文与交叠毫秒）、`unmatchedPrimary` / `unmatchedSecondary`、`stats` 与 `csv` 字段；主轨 / 副轨解析失败分别返回 `primaryParseErrors` / `secondaryParseErrors`（HTTP 400），条目数量超出对齐上限时返回 `alignErrors`（HTTP 400）。
